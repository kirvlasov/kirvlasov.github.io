# Personal Google Drive Backup

## About this application

Personal Google Drive Backup is a private, non-commercial OAuth application configuration used to authorize [rclone](https://rclone.org/) to access my personal Google Drive account.

The application is intended exclusively for my own use and is not offered as a public service.

## Purpose

The application enables me to:

- Authenticate securely with my Google account using OAuth 2.0.
- Access files and folders stored in my Google Drive.
- Download files and export Google Docs, Sheets, and Slides into standard file formats.
- Create and maintain local backups of my own data.

The intended access is read-only. The application is not designed to modify or delete files in Google Drive.

## Data handling

Files downloaded from Google Drive are stored locally on my own devices. No independent cloud storage service, analytics platform, or advertising system is operated by this application.

Authentication and Google Drive access are handled by rclone and Google's official APIs.

For further details, please see the [Privacy Policy](privacy.html).
