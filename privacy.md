# Privacy Policy

**Application:** MyPersonalGmailAppKirillVlasov

**Last updated:** October 16, 2026

## 1. Overview

Personal Google Drive Backup is a private, non-commercial OAuth integration used exclusively by its owner to access and back up personal Google Drive data through the open-source tool [rclone](https://rclone.org/).

The application is not publicly distributed and does not provide services to third-party users.

## 2. Google User Data Accessed

With the account owner's explicit authorization, the application may access:

- Google Drive file and folder metadata, including names, identifiers, and directory structure.
- File contents for downloading and local backup.
- Google Docs, Sheets, and Slides content for export into supported standard file formats.

The application is intended to use read-only Google Drive permissions.

## 3. How Data Is Used

Google user data is accessed exclusively to create and maintain personal backups on devices controlled by the account owner.

The data is not used for advertising, profiling, analytics, or commercial purposes.

## 4. Data Storage and Security

Downloaded files are stored locally on the account owner's devices or backup storage.

OAuth credentials and access tokens are managed and stored locally by rclone.

The application does not operate its own remote server for storing Google Drive files or authentication credentials.

The account owner is responsible for protecting local files, backup storage, and OAuth credentials.

## 5. Data Sharing

Google user data is not sold, rented, or intentionally disclosed to third parties.

Google's official authentication and Drive APIs are used to access the account. The application does not independently transmit downloaded file contents to third-party services.

## 6. Data Retention and Deletion

Downloaded files are retained until the account owner chooses to delete them.

The account owner can revoke the application's Google account access at any time through [Google Account Connections](https://myaccount.google.com/connections).

Locally stored authentication credentials can be deleted from the rclone configuration. Revoking access does not automatically delete previously downloaded backups.

## 7. Website Privacy

This website serves only as an informational homepage and privacy policy for the personal OAuth integration.

It does not intentionally use tracking cookies, advertising, analytics, or data collection forms.

The website is hosted on GitHub Pages, which may process technical access information according to GitHub's own privacy practices.

## 8. Changes to This Policy

This policy may be updated if the application's functionality or data handling practices change.
